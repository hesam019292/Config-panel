# پنل کانفیگ

یک پنل ساده برای مدیریت کاربران و لینک‌های کانفیگ آماده‌شان (vless / vmess / trojan / ss).
این پنل خودش کانفیگ نمی‌سازد — شما لینک کانفیگ را از جای دیگری (پنل ایکس‌ری خودتان) می‌سازید
و اینجا فقط نگه‌داری، نمایش، ویرایش و تغییر سریع IP/دامنه آن انجام می‌شود.

## اجرای محلی

```bash
npm install
cp .env.example .env
# مقادیر ADMIN_USER / ADMIN_PASS / SESSION_SECRET را داخل .env عوض کنید
npm start
```

سپس آدرس `http://localhost:8080` را باز کنید.

## دیپلوی روی Railway

1. این پوشه را در یک ریپازیتوری گیت (مثلاً روی GitHub) قرار دهید و پروژه را در Railway از روی همان ریپو بسازید.
2. در تنظیمات سرویس، سه متغیر محیطی زیر را اضافه کنید:
   - `ADMIN_USER`
   - `ADMIN_PASS`
   - `SESSION_SECRET`
3. Railway خودش متغیر `PORT` را ست می‌کند و برنامه به آن گوش می‌دهد؛ نیازی به تنظیم دستی 8080 نیست،
   چون در کد از `process.env.PORT || 8080` استفاده شده. اگر در تنظیمات Networking پورت را دستی هم
   روی 8080 گذاشتید مشکلی پیش نمی‌آید.
4. دستور استارت به‌صورت خودکار از `package.json` خوانده می‌شود (`npm start`).

### نکته مهم درباره ذخیره‌سازی

داده‌ها (لیست کاربران) در فایل `data/db.json` روی دیسک همان سرویس ذخیره می‌شود. در بسیاری از
پلن‌های Railway فضای دیسک بین دیپلوی‌های جدید پاک می‌شود، یعنی با هر بار push دوباره، لیست
کاربران خالی می‌شود. برای ماندگاری داده بین دیپلوی‌ها یکی از این دو راه را انتخاب کنید:

- یک **Volume** در Railway به سرویس وصل کنید و مسیر `data/` را روی همان Volume نگاشت (mount) کنید.
- یا در آینده `lib/store.js` را به یک دیتابیس واقعی (مثلاً Postgres که خود Railway هم ارائه می‌دهد) وصل کنید.

## قابلیت‌ها

- ورود با یک نام کاربری/رمز ادمین (از `.env`)
- افزودن کاربر جدید همراه با پیست‌کردن لینک کانفیگ آماده
- نمایش/کپی لینک کانفیگ هر کاربر (به‌صورت پیش‌فرض بخشی از آن پنهان است)
- ویرایش نام/یادداشت و **تغییر سریع IP یا دامنه** بدون نیاز به نوشتن کل لینک از نو
  (برای vless/trojan/ss از الگوی آدرس داخل لینک، و برای vmess از دیکد/انکد JSON پایه۶۴ استفاده می‌شود)
- ویرایش دستی کامل متن کانفیگ در صورت نیاز
- حذف کاربر

## ساختار پروژه

```
server.js              نقطه ورود Express
lib/store.js            ذخیره‌سازی ساده روی فایل JSON
lib/configTools.js       تشخیص/جایگزینی IP یا دامنه داخل لینک کانفیگ
middleware/auth.js       محافظت از صفحات با نیاز به ورود
views/                   قالب‌های EJS (ورود، داشبورد، ویرایش)
public/                  CSS و JS سمت کاربر
data/db.json             فایل داده (خودکار ساخته می‌شود)
```
